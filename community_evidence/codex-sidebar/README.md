# Codex sidebar diagnostic evidence

This directory contains reports generated by `codex-sidebar-doctor` and accepted by the
repository-owned GitHub Agent. Each `issue-<number>.json` file is bound to the public
Noosphere Issue with the same number and to its authenticated author.

The accepted fields intentionally contain counts and state classifications, not project
names, project paths, task or thread identifiers, conversation content, or the ordered
identifier arrays themselves. The Agent rejects modified tool identity, inconsistent
classifications, write-action reports, absolute local paths, credential-shaped strings,
copied fixtures, and submissions without explicit public consent.

Acceptance proves that the report matches the deterministic intake contract. It does
not make the report an OpenAI statement, an independent reproduction, a complete
Experience Record, or a callable Skill outcome.
