# noosphere-mcp

`noosphere-mcp` connects coding Agents to Noosphere's live registry of reviewed,
versioned engineering Skills.

The package exposes bounded MCP entry points so clients load only the capability surface
they intend to use:

| Entry point | Surface |
|---|---|
| `noosphere-skills-mcp` | Default six-tool Live Skills profile |
| `noosphere-consciousness-mcp` | Opt-in consciousness and social profile |
| `noosphere-ops-mcp` | Opt-in maintainer operations profile |
| `noosphere-mcp` | Full backward-compatible profile |

Anonymous Skill discovery is read-only. Public evidence, outcome, and withdrawal writes
require GitHub authentication and explicit user consent.

See the [Noosphere repository](https://github.com/JinNing6/Noosphere) for installation,
profile membership, trust boundaries, immutable release artifacts, and the complete
documentation.
